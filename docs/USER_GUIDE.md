# 操作手册

## 1. 安装与打开

第一次使用建议先看 **[分步安装图解](INSTALLATION.md)**，包含扩展权限、脚本安装、源码复制和首次导入的逐步说明。

在 Edge 或 Chrome 中启用 Tampermonkey，使用 README 中的脚本安装入口。若打开后看到源码，可在 Tampermonkey 新建脚本，完整粘贴并保存。登录百度网盘文件页并刷新，右上角会显示助手。重复安装时优先更新原脚本，避免两个版本同时运行。

本工具运行在百度网盘网页中；普通使用者不需要安装 Node.js，不需要启动本地服务。开发时使用的 localhost 安装地址不作为公开版的安装入口。

## 2. 下载和填写 Excel

点击“Excel 导入”中的“下载 Excel 模板”。第一行表头固定为：序号、原始链接、转存路径、备注。前四列不要插列或改动表头；备注右侧可追加任意文字列，例如负责人、分类、补充说明。这些列不参与识别，导出时原样保留。第二行为灰色教学示例，序号栏标注“教学示例（不处理）”，自动跳过。请从第三行开始填写真实任务；不要给真实任务使用这个保留标记。

- 序号：选填，可使用自己的编号。面板中的行号是 Excel 实际行号。
- 原始链接：必填，一行只放一个不同的百度分享链接。可粘贴完整分享文案，保留提取码；也支持链接中的 pwd 参数。
- 转存路径：必填，使用以 / 开头的完整目录，例如 /资源/示例甲。每行可以不同，多级目录会自动创建。
- 备注：选填，供自己记录，导出时保留。

文件保存为 .xlsx。若目录使用公式，先重新计算并保存；建议提交普通文本路径。提取码应随原始链接填写；附加列中的链接和提取码不会参与识别。

## 3. 导入和运行

选择填写好的 Excel，检查任务名称和目标路径，勾选要处理的行，点击“开始处理选中项”。导入本身不会转存。运行期间保持网页打开，避免切换百度账号。

程序按顺序读取原分享、建目录、转存、核验内容、创建分享、核验分享内容和 365 天有效期。新链接带随机提取码。目标目录已有内容时，只有通过核验的同名项才会复用；不会覆盖无法确认一致的内容。

## 4. 文本输入

切换“粘贴分享文本”，填写默认目标目录，粘贴多条分享文案，点击“识别并导入任务”。每条链接后可以另起一行写“目标目录：/资源/示例甲”。未指定时使用默认目录。开始前可在清单中修改目录。

文本输入和 Excel 输入使用同一套转存流程，也支持导出结果表。

## 5. 复制和导出

完成后点击对应的新链接即可复制，或点击“复制全部新链接”。点击“导出结果 Excel”会下载一个新文件，不修改导入原件。

| A | B | C | D | E |
| --- | --- | --- | --- | --- |
| 序号 | 原始链接 | 转存链接 | 转存路径 | 备注 |

C 列是独立新增列，只填写已核验完成的新链接；失败、待核验、未执行时为空。B 列原始链接保持原值；原备注右侧的附加文字列顺延到 F 列及以后，顺序和内容保留。错误信息不额外占用结果表列，请在面板对应行或“诊断与运行日志”中查看。

## 6. 暂停、重试和恢复

“暂停”会在安全检查点停止，当前请求可能需要先完成。“重试失败项”只处理失败且未完成的任务。已转存但分享失败的任务，在进度有效时从后续步骤继续。

刷新后，在同一浏览器、同一百度账号下，导入原先那份未修改的四列文件，再同步账号与进度或开始处理即可恢复。文本任务需要相同的文本和目标目录。修改表格、转换旧模板或清理扩展数据，会使原进度无法按同一输入恢复。升级前先导出当前结果。

不要把五列结果表当成恢复进度的输入文件。需要另开一批任务时，将需要的行整理进新的四列模板。

## 7. 常见问题

**安装后看到源码：** 使用 Tampermonkey 的添加/编辑脚本功能粘贴完整源码并保存，然后刷新网盘文件页。

**未找到四列模板：** 重新下载模板，检查第一行四个表头和列顺序。

**源链接手动打开正常，但脚本失败：** 查看失败步骤与接口，确认脚本使用的链接和提取码、当前账号一致。可能与网页接口或访问凭据有关；保留脱敏后的诊断信息用于反馈。

**目标目录含问号等符号：** 不支持的目录字符会转为对应全角字符。面板展示实际目录并给出修正提示。

**同名项不一致：** 检查目标目录；程序不会仅凭名字就分享已有文件。可自行确认后改用新的目标目录。

**请求结果不明：** 先核对网盘文件或“我的分享”，不要反复提交或删除进度，以免重复写入。

**分享有效期核验失败：** 查看有效期诊断。程序不会自动改用永久有效；未通过核验的新分享会尝试取消。

反馈问题时提供版本号、浏览器、操作步骤、失败步骤及脱敏日志。公开 Issue 中不要贴 Cookie、Token、个人分享链接、提取码或未脱敏表格。
