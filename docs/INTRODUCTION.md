# 百度网盘批量转存与换链助手

一个因为不想反复点“新建文件夹”，最后折腾出来的油猴小工具。

## 为什么做这个项目

起因很简单：我被“新建文件夹”这件事折腾烦了 😂

打开一个分享，里面是 01、02、03、04……一集一集的文件。想把不同的剧整理好，就得先建文件夹，再选目录、转存。换一部剧？再来一遍。

试了几个现有的开源项目，总有些地方和自己的需求对不上。于是拉上 AI，边提需求、边试、边改，做出了这个小工具：我在表格里填好链接和目录，它负责建文件夹、转存，再把新分享链接整理回来。

本来只是想给自己省点事，用着还挺顺手，干脆开源出来。有同款烦恼的朋友，欢迎拿去用，少点几次鼠标也好。遇到 bug 或者有新点子，来提个 Issue，咱们慢慢修、慢慢加。

## 它能帮你干什么

把百度网盘分享链接和保存目录填进 Excel，剩下的重复操作交给它：

- **先建好文件夹，再转存。** 每行可以填不同目录，不用一部剧一部剧地手动建。
- **转存完，顺手换成自己的分享链接。** 对照原分享核验内容，生成 365 天有效期、带随机提取码的新链接。
- **结果帮你排好队。** 导出时，“转存链接”就在“原始链接”右边，备注和后面自己加的文字列也会保留。失败或没完成的行留空，不拿半成品交差。
- **不想填表也行。** 直接粘贴分享文案；完成的链接点一下就能复制，失败的任务可以单独重试。

模板里放了一行教学示例，看着填就行。示例会按标记跳过，删掉也没关系。

## 想试试？

先安装 Tampermonkey，再[安装脚本](https://raw.githubusercontent.com/Sylvia-qiu/baidu-pan-excel-transfer/main/baidu-pan-excel-transfer.user.js)，打开百度网盘文件页就能看到面板。不用自己搭服务器。

具体步骤在[操作手册](USER_GUIDE.md)，也可以先回[首页](../README.md)看看。脚本目前只支持百度网盘。
