# 百度网盘批量转存与换链助手｜Excel 导入 · 油猴脚本

支持 **Excel 批量转存、文本链接导入、自动创建文件夹、批量生成自己的百度网盘分享链接**。每行可指定不同目标目录，转存后核验内容，生成 365 天有效期、随机提取码的新链接，再导出 Excel。

**Baidu Netdisk Batch Transfer & Share Link Generator** — a Tampermonkey userscript with Excel import/export, per-row destination folders, automatic folder creation, and verified 365-day share links.

[安装油猴脚本](https://raw.githubusercontent.com/Sylvia-qiu/baidu-pan-excel-transfer/main/baidu-pan-excel-transfer.user.js) · [下载 Excel 模板](examples/import-template.xlsx) · [查看操作手册](docs/USER_GUIDE.md) · [反馈问题 / 功能建议](https://github.com/Sylvia-qiu/baidu-pan-excel-transfer/issues)

## 为什么做这个项目

起因很简单：我被“新建文件夹”这件事折腾烦了 😂

打开一个分享，里面是 01、02、03、04……一集一集的文件。想把不同的剧整理好，就得先建文件夹，再选目录、转存。换一部剧？再来一遍。

试了几个现有的开源项目，总有些地方和自己的需求对不上。于是拉上 AI，边提需求、边试、边改，做出了这个小工具：我在表格里填好链接和目录，它负责建文件夹、转存，再把新分享链接整理回来。

本来只是想给自己省点事，用着还挺顺手，干脆开源出来。有同款烦恼的朋友，欢迎拿去用，少点几次鼠标也好。遇到 bug 或者有新点子，来提个 Issue，咱们慢慢修、慢慢加。

## 适合哪些场景

- **Excel 批量转存百度网盘**：一行一个原始链接，每行保存到不同目录。
- **批量换链 / 重新分享**：将原链接对应的内容保存到自己网盘，再生成自己的分享链接。
- **分享文案批量处理**：直接粘贴多条百度网盘分享文本，识别链接和提取码。
- **整理转存结果**：点击复制新链接，或导出“原始链接 / 转存链接”对应表，保留备注和附加文字列。

这里的“换链”通过转存后重新创建分享实现，仅支持百度网盘。

这是运行在百度网盘网页上的 Tampermonkey 用户脚本。日常使用不需要 Node.js，也不需要启动本地服务。

当前版本：**3.1.1**。

## 安装

**第一次安装？打开 [分步安装图解](docs/INSTALLATION.md)**：从安装油猴到复制源码、保存脚本，每一步都有示意图。

1. 在 Edge / Chrome 中安装并启用 Tampermonkey，按扩展提示允许运行用户脚本。
2. [点击安装最新脚本](https://raw.githubusercontent.com/Sylvia-qiu/baidu-pan-excel-transfer/main/baidu-pan-excel-transfer.user.js)。如果浏览器只展示源码，在 Tampermonkey 中添加脚本，粘贴完整源码并保存。
3. 登录并刷新 [百度网盘文件页](https://pan.baidu.com/disk/main)，右上方会出现助手面板。

从本项目旧版升级时，请更新原脚本，保留它的存储数据。脚本名称和 namespace 保持不变。但 3.1.0 更换了导入格式，旧七列表的进度不能通过转换后的新文件恢复；升级前请导出旧任务结果。

## 使用

### Excel 导入

在助手的“Excel 导入”页点击“下载 Excel 模板”，或下载 [含教学示例的导入模板](examples/import-template.xlsx)。前四列使用最新模板，备注右侧可追加文字列：

| 列 | 表头 | 用途 |
| --- | --- | --- |
| A | 序号 | 选填，原样保留 |
| B | 原始链接 | 必填，百度分享链接或完整文案，可含提取码 |
| C | 转存路径 | 必填，例如 /资源/第一部，每行可不同 |
| D | 备注 | 选填，原样保留 |

导入后检查清单，点击“开始处理选中项”。成功链接可点击复制，也可批量复制或导出 Excel。

导出结果前五列为：**序号、原始链接、转存链接、转存路径、备注**。“转存链接”是新增的独立 C 列，仅核验成功时填写；失败、待核验和未执行的行留空。原始链接保留，不覆盖原文件。备注右侧的附加文字列不参与识别，导出时按原顺序保留。错误详情在助手面板和日志中查看。

旧七列模板和导出的五列结果表不能直接导入。请将需要处理的数据填入最新四列模板；恢复进度时选择之前导入的同一份四列原文件。普通文本目录最稳妥；公式目录需要先在 Excel 计算并保存，插列导出后不要依赖公式引用自动调整。

### 文本导入

切换到“粘贴分享文本”，填写默认目标目录，然后粘贴多条百度网盘分享文案。以下链接仅为格式占位符：

```text
https://pan.baidu.com/s/1EXAMPLE_A 提取码：abcd
目标目录：/资源/第一部

https://pan.baidu.com/s/1EXAMPLE_B?pwd=1234
目标目录：/资源/第二部
```

点击“识别并导入任务”。每条链接的提取码放在链接后或 URL 的 `pwd` 参数里；“目标目录”可省略，此时使用默认目录。开始前可在清单中逐条修改目录。文本任务也支持导出 Excel。

## 功能与处理规则

- 自动创建目标路径中缺少的目录；将目录名中的 `: * ? " < > |` 换成对应全角字符，并记录修正说明。
- 同名文件存在时，检查类型、大小和内容校验值；一致的复用，缺少的转存。已有文件夹在分享前递归核验，内容不一致则停止。
- 新分享只包含与原分享对应的文件或文件夹，不会分享整个目标目录及其中无关文件。
- 请求 365 天有效期，生成随机四位提取码，再核验分享记录中的文件标识和到期时间。未通过核验的新分享会尝试取消，不会作为成功结果导出。
- “重试失败项”只处理失败任务；已完成项跳过，已转存项从后续步骤继续。
- 进度保存在当前浏览器的 Tampermonkey 存储中，按百度账号与导入内容区分。重新导入同一原表可恢复进度。
- 暂停会等待当前请求结束。运行期间请保持页面打开。

## 使用边界与数据

脚本仅支持百度网盘，依赖百度网页接口和当前登录状态。百度接口调整、验证码、容量不足、转存数量限制及账号权限可能导致任务失败；不会绕过这些限制。

如果网络中断导致转存或分享请求的结果不明确，脚本会停在待核实状态，避免重复写入。请核对网盘文件或“我的分享”后再处理，不要清理任务存储。

Excel 和粘贴文本在浏览器本地解析；网盘请求发给百度网盘。脚本没有自己的上传服务器，不要求提供 Cookie 或 Token。任务进度会在本地保存链接及提取码，建议只在自己的浏览器中使用。仅处理你有权保存和分享的内容。

## 开发与验证

需要 Node.js 22 或更高版本。ExcelJS 4.4.0 已内置，无需安装额外依赖。

```sh
npm test
npm run test:integration
npm run build
npm run template
```

- `core.js`：表格与文本解析、目录修正、任务状态和分享核验。
- `api.js`：百度网页接口适配。
- `app.js`：页面面板与任务操作。
- `build.cjs`：将源码及 ExcelJS 打包为可直接安装的 `.user.js`。
- `verify-server.cjs`：仅供本地测试的模拟接口，绑定 `127.0.0.1:8597`；不会连接真实网盘。

自动测试使用虚构链接和模拟账号。真实账号的转存、分享流程曾由使用者验证通过；这不代表每个账号、分享链接及未来接口版本都已验证。
